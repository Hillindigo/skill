# Skill

这里收录可复用的 Codex Skills，帮助 Codex 完成具体而明确的工作任务。

## internship-project-interview-bank

根据实习简历、项目代码仓库和个人职责，生成代码可信、业务具体的项目面试题库。

它可以：

- 拆解简历中的项目目标、技术实现和个人职责；
- 结合代码入口、调用链、数据模型和异常处理核验简历表述；
- 生成项目总体与职责分层的面试题；
- 为每道题生成 1—2 分钟口语回答和业务化详细解答；
- 为复杂业务补充 Mermaid 架构图、流程图、时序图或关系图；
- 校验 Markdown 标题、题号、回答结构和图示代码块。

该 Skill 只总结通用的实习项目面试题库生成方法，不包含特定项目内容。

## video-subtitle-to-word

将公开抖音视频整理成可编辑的 Word 文档。

它可以：

- 从抖音分享链接获取视频内容；
- 将视频中的中文语音转换为逐段字幕；
- 生成带时间戳的完整字幕版 Word；
- 将字幕整理成保留博主原话的分点文章版 Word；
- 在导出前逐条查看、修改和校对字幕；
- 保留原始转写内容与编辑后的内容，方便复核和追溯。

该工具适合把公开抖音视频快速整理为可阅读、可编辑、可保存的文字材料。生成内容属于语音转写结果，发布或正式使用前建议进行人工校对。
